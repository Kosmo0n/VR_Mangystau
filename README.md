# VR Mangystau — Университеттік веб-жоба

> **Маңғыстау облысының табиғи мұрасы мен мұнай-газ өнеркәсібін таныстыратын заманауи виртуалды білім беру және туризм платформасы.**

---

## 📋 Жоба туралы (О проекте)

**VR Mangystau** — Маңғыстау облысының көрікті жерлерін, табиғи қорықтарын (Бозжыра, Шерқала, Каспий теңізі), мұнай-газ саласының технологиялық процестерін цифрлық форматта таныстыратын толыққанды Full-Stack веб-платформа.

Сайтта ауыр 3D-қозғалтқыштардың орнына YouTube 360° панорамалық бейнелері қолданылып, пайдаланушыға кез келген құрылғыда (ДК, смартфон, планшет) еркін көру бұрышын айналдыру мүмкіндігі берілген.

## 🛠 Технологиялық стек (Tech Stack)

### Frontend
* **HTML5** — семантикалық, қолжетімді белгілеу
* **CSS3** — CSS Grid, Flexbox, CSS Custom Properties, микроанимациялар
* **Vanilla JavaScript (ES6+)** — фреймворктерсіз таза, оңай өңделетін код
* **Responsive Design** — барлық экран өлшемдеріне (320px — 1920px) толық бейімделген
* **YouTube 360° Embed API** — интерактивті панорамалық бейнелер

### Backend
* **Node.js** (v18+)
* **Express.js** — REST API маршруттау және статикалық файлдарды тарату
* **SQLite** (`better-sqlite3` немесе кіріктірілген `node:sqlite`) — жылдам әрі сенімді реляциялық деректер қоры
* **express-session** — қауіпсіз серверлік сессиялар
* **bcryptjs** — пайдаланушы құпия сөздерін бір жақты криптографиялық хэштеу

## 🚀 Жобаны іске қосу (Quick Start)

Жобаны іске қосу үшін компьютеріңізде [Node.js](https://nodejs.org/) (18 немесе одан жоғары нұсқасы) орнатылған болуы қажет.

### 1. Тәуелділіктерді орнату:
```bash
npm install
```

### 2. Деректер қорын бастапқы баптау:
```bash
npm run db:init
```
*Бұл пәрмен барлық кестелерді құрып, 3 туристік нысанның, 3 оқу курсының, 15 толық сабақтың және 15 тест сұрақтарының деректерін SQLite базасына енгізеді.*

### 3. Серверді іске қосу:
```bash
npm run dev
```
немесе:
```bash
npm start
```

### 4. Сайтты браузерден ашу:
Браузерде келесі мекенжайға өтіңіз:
👉 **[http://localhost:3000](http://localhost:3000)**
